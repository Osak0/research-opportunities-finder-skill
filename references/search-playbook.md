# 科研机会检索指南

## 定位可信入口

1. 用户指定机构时，从机构官网进入院系、研究中心、团队目录或招募页面。未指定机构时，先按研究方向搭配地区、远程、参与时间等已知条件搜索。
2. 同时搜索导师与项目公告。可组合方向词与“本科科研”“科研助理”“科研实习”“本科生进组”“undergraduate research”“research internship”“join us”。查跨校项目时，加入“外校申请”“校际”“visiting students”等关键词，随后核实公告原文。
3. 从搜索摘要、转载、论文作者信息追溯到机构、团队或发布者的公开原始页面。论文和研究介绍可支持方向判断，招募资格和名额以招募说明为依据。

## 记录覆盖与资格

- 查明谁招募、加入哪个团队、在哪里开展工作，再核对校籍、年级和时间条件。合作项目核对各方职责。
- 按教师或项目去重，保留能够直接复核的来源。同一教师的不同项目分别核对各自的资格与时效。
- 记录精读数量、未能访问的页面和停止原因。仅有摘要、转载或无法核实归属的结果留作待核实线索。
- 在已知目标范围内优先核对最新公告。能够查看发布日期时保留该日期，对照核查日期判断公告时效。
